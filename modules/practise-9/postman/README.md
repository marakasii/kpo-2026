# Postman: ручные запросы

1. Запустите Docker Compose из корня репозитория:
   ```bash
   docker compose -f modules/practise-9/docker-compose.yml up --build -d
   ```
2. В Postman выберите **Import** и файл `practise-9-manual.postman_collection.json` из этого каталога.
3. Откройте папку **1. Подготовка**. По очереди отправьте запросы **01–04** кнопкой **Send**: health, регистрация, пополнение и выпуск ключа.
4. Откройте **05 — Отправить новый prompt**, вкладку **Body**. Измените `prompt` и при необходимости `maxTokens`, нажмите **Send**.

Environment создавать не нужно. Идентификаторы и ключ автоматически сохраняются в Variables коллекции. По умолчанию `baseUrl = http://localhost:8080`, `model = qwen3:4b`. При запуске с другой `OLLAMA_MODEL` измените переменную `model` в коллекции.

Каждый Send запроса **05** создаёт новый ключ идемпотентности и новый платный запрос. Запрос **06** повторяет последний успешный запрос без нового списания. Остальные запросы показывают состояние генерации, баланс, журнал операций и тарифы.

Отзыв ключа вынесен в отдельную папку: после него для продолжения отправьте запрос **04** заново. Повторное выполнение запроса **03** снова пополнит баланс, а **02** создаст нового пользователя и сбросит сохранённые ID/ключ.

`practise-9.postman_collection.json` — отдельная коллекция для автоматического прогона проверок через Run collection / Newman.
